== SPARK status (checked 2026-11-09)

`runners/must/` carries documents that call its SPARK conversion complete
(`SPARK-CONVERSION-COMPLETE.md`, `SPARK-STATUS.md` and five
`SPARK-*-COMPLETE.md`). The Ada sources do not support that. No `.ads`,
`.adb` or `.gpr` file in `runners/must/src` or `mustfile/src` sets
`SPARK_Mode`, and there is no `.adc` configuration file, so `gnatprove`
analyses none of it. The only contract aspects are four `Pre` and eight `Post`
aspects on the eight bounded-string conversion functions in
`runners/must/src/must_types.ads`. There are no `Global`, `Depends`,
`Contract_Cases` or `Loop_Invariant` aspects. The record types whose comments
say "with SPARK contracts" (`must_types.ads` lines 66–135) carry none.
Outside SPARK the twelve aspects are run-time assertions at most, not
discharged proof obligations, so SPARK-1 is `OPEN`, not `PROVEN`. The
documents carry a status correction at the top and are kept as history.

`runners/must/src` and `mustfile/src` are two diverging implementations, not
copies. `must.adb`, `must_types.ads` and `must_types.adb` differ: the
`runners/must` tree uses `Ada.Strings.Bounded`, while `mustfile/src` uses
indefinite containers and unbounded strings, and has no contract aspects at
all. A proof about one tree says nothing about the other, so any SPARK work
must name its tree. Which tree survives belongs to the runner-only
consolidation of this repository (standards ultraplan Q8).
